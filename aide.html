🚀 Bienvenue dans Gestion Locative

Cette application vous permet de gérer facilement vos biens immobiliers, vos locataires et tous les documents associés.

💡 Première utilisation ?
Suivez ces étapes pour démarrer rapidement avec l'application.

Étape 1 : Configurer le stockage

Avant de commencer, configurez un dossier local pour stocker vos documents :

  1. Allez dans Paramètres (⚙️)
  2. Cliquez sur "Choisir un dossier"
  3. Sélectionnez un dossier sur votre ordinateur
  4. Accordez les permissions nécessaires

Étape 2 : Ajouter un bien immobilier

  1. Cliquez sur "Biens" dans le menu
  2. Remplissez les informations du bien (adresse, superficie, etc.)
  3. Ajoutez des photos et documents si nécessaire
  4. Sauvegardez

Étape 3 : Enregistrer un propriétaire

  1. Allez dans "Propriétaires"
  2. Ajoutez les coordonnées du propriétaire
  3. Associez-le à un ou plusieurs biens

Étape 4 : Ajouter un locataire

  1. Cliquez sur "Locataires"
  2. Remplissez les informations du locataire
  3. Joignez les documents (pièce d'identité, justificatifs, etc.)

Étape 5 : Générer un bail

  1. Rendez-vous dans "Baux"
  2. Sélectionnez le bien, le propriétaire et le locataire
  3. Configurez les conditions (loyer, durée, clauses)
  4. Générez et imprimez le bail

📖 Guide : Créer un bail complet

1. Préparer les informations

Avant de commencer, assurez-vous d'avoir :

  • Les informations complètes du bien
  • Les coordonnées du propriétaire
  • Les informations du locataire
  • Le montant du loyer et des charges
  • Les diagnostics obligatoires

2. Choisir le type de bail

Trois types de baux sont disponibles :

  • Location vide : Durée minimale 3 ans (6 ans pour personne morale)
  • Location meublée : Durée minimale 1 an (9 mois pour étudiants)
  • Location mixte : Usage habitation + professionnel
💡 Bon à savoir :
Le dépôt de garantie est limité à 1 mois de loyer pour une location vide et 2 mois pour une location meublée.

3. Configurer les clauses

Personnalisez votre bail avec les clauses optionnelles :

  • Révision annuelle du loyer (IRL)
  • Clause de résiliation facilitée
  • Clause de solidarité (colocation)
  • Autorisation préalable pour travaux
  • Interdiction de sous-location

4. Vérifier les diagnostics

Cochez les diagnostics obligatoires selon votre bien :

  • DPE (obligatoire pour tous)
  • Diagnostic amiante (si construction avant 1997)
  • CREP - Plomb (si construction avant 1949)
  • Diagnostic gaz et électricité (si installation > 15 ans)
  • ERP - État des Risques et Pollutions

5. Générer et imprimer

  1. Vérifiez toutes les informations
  2. Cliquez sur "Générer le bail"
  3. Prévisualisez le document
  4. Imprimez en 2 exemplaires originaux
  5. Faites signer les deux parties
⚠️ Important :
Le bail doit être signé avant la remise des clés. Conservez précieusement un exemplaire signé.

📖 Guide : Gérer les documents

Stocker des documents

  1. Configurez d'abord un dossier de stockage dans les paramètres
  2. Lors de l'ajout d'un bien, propriétaire ou locataire, cliquez sur "Ajouter un document"
  3. Sélectionnez le fichier (PDF, image, scan)
  4. Le fichier est automatiquement copié dans votre dossier

Organiser les fichiers

L'application organise automatiquement vos fichiers par catégorie :

📁 Dossier de stockage/ 📁 biens/ 📁 bien_123456/ 📄 photo_1.jpg 📄 diagnostic_dpe.pdf 📁 proprietaires/ 📁 proprio_789012/ 📄 carte_identite.pdf 📁 locataires/ 📁 locataire_345678/ 📄 justificatif_domicile.pdf
✅ Avantage :
Vous gardez le contrôle total de vos fichiers. Ils restent accessibles même sans l'application.

📖 Guide : Sauvegarder et restaurer

Créer une sauvegarde

  1. Allez dans Paramètres
  2. Cliquez sur "Exporter toutes les données"
  3. Un fichier JSON est téléchargé avec toutes vos informations
  4. Conservez ce fichier en lieu sûr (cloud, clé USB, etc.)

Restaurer une sauvegarde

  1. Allez dans Paramètres
  2. Cliquez sur "Importer des données"
  3. Sélectionnez votre fichier de sauvegarde JSON
  4. Confirmez l'import
⚠️ Attention :
L'import remplace les données existantes. Faites une sauvegarde avant d'importer si vous avez des données importantes.

Fréquence recommandée

Nous recommandons de faire une sauvegarde :

  • Après chaque ajout important (nouveau bail, nouveau bien)
  • Une fois par semaine si vous utilisez l'application régulièrement
  • Avant toute mise à jour de l'application
  • Avant de vider le cache ou les données

❓ Questions fréquentes

L'application fonctionne-t-elle hors ligne ? ▼
Oui ! Gestion Locative est une PWA (Progressive Web App) qui fonctionne entièrement hors ligne une fois installée. Toutes vos données sont stockées localement sur votre appareil via IndexedDB.
Mes données sont-elles envoyées sur internet ? ▼
Non, absolument pas. Toutes vos données restent sur votre appareil. Aucune information n'est envoyée vers des serveurs externes. Vous avez le contrôle total de vos données.
Puis-je utiliser l'application sur plusieurs appareils ? ▼
Les données sont stockées localement sur chaque appareil. Pour synchroniser, exportez vos données depuis un appareil et importez-les sur l'autre via le fichier JSON. Une synchronisation automatique est prévue dans une future mise à jour.
Quelle est la limite de stockage ? ▼
IndexedDB permet généralement de stocker plusieurs centaines de Mo à plusieurs Go selon le navigateur. Pour les fichiers (photos, PDF), la limite dépend de l'espace disque disponible sur votre ordinateur.
Les baux générés sont-ils conformes à la loi ? ▼
Les modèles de baux sont conçus pour être conformes à la loi du 6 juillet 1989 et aux textes en vigueur. Cependant, nous recommandons de faire vérifier vos baux par un professionnel (avocat, notaire) pour s'assurer qu'ils correspondent à votre situation spécifique.
Comment supprimer toutes mes données ? ▼
Allez dans Paramètres > Zone dangereuse > "Supprimer toutes les données". Cette action est irréversible, assurez-vous d'avoir fait une sauvegarde avant. Vous pouvez également vider les données du navigateur via les paramètres de celui-ci.
L'application nécessite-t-elle une installation ? ▼
Non, vous pouvez l'utiliser directement dans votre navigateur. Cependant, vous pouvez l'installer comme application (bouton + dans la barre d'adresse) pour un accès plus rapide et une meilleure expérience utilisateur.
Quels navigateurs sont supportés ? ▼
L'application fonctionne sur Chrome, Edge, Opera et Brave. Pour le stockage de fichiers, la File System Access API nécessite Chrome 86+, Edge 86+ ou Opera 72+. Firefox et Safari ont un support limité de certaines fonctionnalités.
Que faire en cas de bug ou de problème ? ▼
  1. Rafraîchissez la page (Ctrl+F5 ou Cmd+Shift+R)
  2. Videz le cache dans Paramètres
  3. Vérifiez la console du navigateur (F12) pour les erreurs
  4. Exportez vos données par précaution
  5. Si le problème persiste, consultez la section Technique

🔧 Informations techniques

Technologies utilisées

  • PWA (Progressive Web App) : Application web installable fonctionnant hors ligne
  • IndexedDB : Base de données locale pour stocker vos informations
  • File System Access API : Accès au système de fichiers local
  • Service Worker : Mise en cache pour fonctionnement hors ligne
  • PicoCSS : Framework CSS minimaliste et élégant

Raccourcis clavier

  • F12 : Ouvrir les outils de développement
  • Ctrl + P : Imprimer (dans la prévisualisation)
  • Ctrl + S : Sauvegarder (formulaires)

Limites de stockage

📊 IndexedDB :
• Minimum garanti : 50 Mo
• Maximum typique : 10% de l'espace disque disponible
• Chrome/Edge : jusqu'à 60% de l'espace disque

📁 Fichiers (File System API) :
• Limité uniquement par l'espace disque disponible
• Les permissions doivent être accordées par l'utilisateur

Dépannage avancé

Réinitialiser IndexedDB

Depuis la console du navigateur (F12) :

// Supprimer la base de données indexedDB.deleteDatabase('GestionLocativeDB'); // Puis rechargez la page location.reload();

Vérifier le Service Worker

// Vérifier l'état du Service Worker navigator.serviceWorker.getRegistrations() .then(registrations => console.log(registrations)); // Désinscrire tous les Service Workers navigator.serviceWorker.getRegistrations() .then(registrations => { registrations.forEach(r => r.unregister()); });

Vider complètement le cache

Méthode 1 : Via l'application

  1. Allez dans Paramètres
  2. Cliquez sur "Vider le cache"
  3. Rechargez la page

Méthode 2 : Via le navigateur

  1. F12 > Application > Storage
  2. Cliquez sur "Clear site data"
  3. Confirmez et rechargez
